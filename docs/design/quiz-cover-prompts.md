# Quiz cover art prompts — top 70 (by virality)

Compact image prompts for the **quiz-pick card covers**, in priority order from the
autoresearch backlog (`content/topic-backlog.tsv`). Generate each, save as
`public/quizzes/<slug>.jpg`, then run `pnpm build:art`.

## How to use
1. Set the **STYLE** block below as a global style / prefix for every image (so all 70 match and the grid feels cohesive).
2. Generate each numbered line as its own image.
3. Name the file exactly the `slug` shown → `public/quizzes/<slug>.jpg`.
4. **Landscape 3:2** (e.g. 1200×800).

## STYLE (use for every cover — keep identical)
> Soft 2D animated-storybook illustration, painterly cel shading, warm golden-hour biblical / ancient-Near-East palette (cream, sand, rose, gold, soft teal accents), gentle diffused light, subtle canvas texture, reverent and hopeful, **symbolic and uncluttered with one clear central focal point**, horizontal 3:2 composition. No text, no lettering, no logos. No depiction of God or Jesus' face; any human figures are distant or silhouetted.

## RULES
- Symbolic / scenic / objects — not close-up faces. Distant or silhouetted figures are fine.
- One focal subject, lots of soft negative space (text/UI sits around it).
- Same lighting + palette across all 70 so the homepage grid is cohesive.
